# AgentGlimpse GitHub launch package

**Selected name: AgentGlimpse.** Check agent activity and Codex usage limits with a quick glance at the menu bar.

**Tagline:** Your agents’ status. Your Codex limits. One quiet glance.

Start with the [repository README](agentglimpse/README.md), then the [research and evidence](agentglimpse/launch/RESEARCH.md), [name rationale](agentglimpse/launch/NAMING.md), and [open decisions](agentglimpse/launch/OPEN_DECISIONS.md).

The folder contains the requested GitHub text files plus configuration examples, troubleshooting and uninstall guides, third-party notices, a rename plan, launch copy, release notes, a visual-asset brief, and documentation checks. It contains no application code or binary; merge it into the reviewed source checkout. Current executable names and data paths remain AgentBeacon until the code is migrated.

The requested ChatGPT history reader was unavailable. Research used the supplied ChatGPT preview, relevant local development task history, and the actual 1.4.9 source. It does not claim a comprehensive search of the ChatGPT account.

The package corrects stale documentation about quota percentages versus token counts, the idle cat, ongoing refresh, and notification/hook message retention. It keeps unknowns explicit rather than inventing implementation details.

The main unresolved launch items are the public onboarding gate, license/copyright identity, final repository identity and rename, asset rights, security-report route, compatibility/signing evidence, and release validation. A full MIT candidate is included separately; the root LICENSE records that no license has been adopted.

Read the [launch checklist](agentglimpse/launch/CHECKLIST.md) before publishing. Package validation results are in [VALIDATION_RESULTS.txt](agentglimpse/launch/VALIDATION_RESULTS.txt).
