AgentGlimpse brings agent activity and Codex usage limits into a compact native Mac companion. It carries forward the menu bar pill, animated idle cat, and glass usage panel developed under the AgentBeacon name.

## Included behavior

- Agent activity states with recognizable provider badges.
- Local Codex lifecycle tracking and optional desktop/state-file integrations.
- Codex quota percentages, reported reset times, and account-plan label.
- Explicit unavailable and stale states, including the missing-Spark fallback.
- Content-sized usage panel, clear controls, Dock presence, and standard app quitting.
