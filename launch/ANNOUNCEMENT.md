Use after the public release is available and the placeholders are resolved.

I built AgentGlimpse, a native Mac companion that keeps AI agent activity in a small menu bar pill.

It shows when an agent is working, waiting for you, or finished. Click the pill to see Codex usage percentages and reset countdowns in a glass panel. When everything is quiet, a tiny animated ginger cat takes over.

It grew out of AgentBeacon, with a lot of attention to the small details: recognizable agent badges, a panel that fits its content, and unavailable usage data shown honestly.

Local Codex activity is read from session events; optional desktop readers and state-file integrations extend coverage. The README explains compatibility and privacy, including when local logs can contain message excerpts.
